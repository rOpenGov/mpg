# Vehicle fuel economy

Retrieve vehicle fuel economy by vehicle ID

## Usage

``` r
feVehicle(id = NULL, pick = FALSE, ...)
```

## Arguments

- id:

  A vehicle ID number.

- pick:

  A logical indicating whether to select the ID number via an
  interactive menu.

- ...:

  Options passed to
  [`pickVehicle`](https://ropengov.github.io/mpg/reference/pickVehicle.md),
  if `pick=TRUE`.
