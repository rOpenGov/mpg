# My MPG vehicles

Retrieve My MPG vehicle data by make and model

## Usage

``` r
mympgVehicles(make, model, pick=FALSE, graphics=TRUE, ...)
```

## Arguments

- make:

  A character string containing a vehicle make.

- model:

  A character string containing a vehicle model.

- pick:

  A logical indicating whether to select the ID number via an
  interactive menu.

- graphics:

  If `pick=TRUE`, a logical indicating whether to use graphical menus
  (the default) or, if `FALSE`, text-based menus.

- ...:

  Ignored.
