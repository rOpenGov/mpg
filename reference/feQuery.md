# API Query

Execute an API query

## Usage

``` r
feQuery(op, baseurl = "http://www.fueleconomy.gov/ws/rest/", ...)
```

## Arguments

- op:

  A character string containing an API operation, and associated
  arguments.

- baseurl:

  The base URL for conducting the API query.

- ...:

  Ignored.
